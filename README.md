# chessmate-lab

Un jeu d'échecs jouable dans le navigateur, construit pas à pas comme **projet d'apprentissage** : développement d'un jeu de A à Z, et travail avec les outils Claude (Claude Code dans VS Code, Cowork, CLAUDE.md, skills, Git/GitHub).

## Statut

Phase 0 — mise en place. Aucun code jouable pour l'instant.

## Ce qui est prévu

| Phase | Contenu |
|---|---|
| 0 | Mise en place du projet et des outils |
| 1 | Moteur de règles complet, testé |
| 2 | Plateau avec Phaser, 2 joueurs sur le même écran, publication en ligne |
| 3 | Adversaire ordinateur |
| 4 | Partie en ligne entre 2 joueurs |

Détails : [`docs/roadmap.md`](docs/roadmap.md).

## Technologies

TypeScript · Phaser · Vite · Vitest · Node.js
